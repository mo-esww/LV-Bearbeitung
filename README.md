# Fußbodenheizung Positionen-Analysator ♨️

Ein Streamlit-basiertes Tool zur automatischen Analyse von Leistungsverzeichnissen und Angeboten (PDF). 

## Features
- **PDF-Parsing**: Durchsucht mehrseitige Dokumente nach Gewerk-Spezifikationen.
- **Keywords**: Filtert nach Fußbodenheizung, Heizkreisverteilern, Stellantrieben u.v.m.
- **Export**: Generiert übersichtliche Tabellen & CSV-Downloads.
